## About

This repository contains my Java coursework completed as part of my college programming curriculum. Each week's folder contains the tasks assigned during that week, along with the corresponding Java programs and solutions.

The repository is intended to:

* Maintain a record of weekly Java assignments
* Track my progress throughout the course
* Practice Java programming fundamentals
* Strengthen problem-solving and logical thinking
* Provide a structured reference for revision
* Document coursework completed under faculty/mentor guidance
